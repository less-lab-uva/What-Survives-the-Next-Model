### Rules that Apply to Both Prompts
- Be fully self-contained. Do not reference the paper, its authors, its system name, or any dataset names from the paper.
- Write in second person, addressed to the LLM that will run on the benchmark.
- All fields must be populated with concrete content - no placeholder text of any kind.
- Do not ask the LLM for justification or explanation unless the task itself requires it as output.
- After drafting both prompts, verify self-containment: confirm that neither prompt contains the paper's system name, author names, dataset names, or any phrasing that presupposes knowledge of the paper.

- The only inputs available to the LLM are raw, unprocessed fields taken directly from the dataset at the very start of the pipeline. Do not assume any intermediate data that the paper's methodology generated will be provided as inputs. If the paper's methodology produces intermediate artifacts, the prompt must instruct the LLM to produce them internally as part of its own reasoning, not receive them as inputs.
- The Input section and Output section of both prompts must be grounded in the concrete reference examples provided at the bottom of this meta prompt. The field names, content types, and structure of the input and output must exactly match what is shown in the reference examples.
- Embed the reference examples as a few-shot demonstration inside both Prompt A and Prompt B. Each prompt must include an Example section placed after the Output section and before the Instructions section. This Example section must reproduce the reference examples exactly as provided at the bottom of this meta prompt in the same JSON format, without modification or summarization.

### Steps vs Instructions Boundary
This distinction applies to Prompt B and must be kept clean:
- Steps: The methodology - what to reason about and in what order. Heuristics, weights, decision rules, tie-breaking logic, and edge case handling all go here, embedded within the relevant step.
- Instructions: Hard behavioural constraints - what the LLM must and must not do, and how to format output. Keep these brief and rule-like.
- Do not duplicate content across Steps and Instructions.
